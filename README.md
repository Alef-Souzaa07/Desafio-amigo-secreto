Ola, este projeto consiste em realizar um sorteio entre amigos para celebrar o "Amigo secreto".
O usuario começara inserindo um nome ou apelido do amigo
Obs: Se o campo permanecer vazio, o usuario recebera um alerta inforando que ele deve informar um nome valido de um amigo.
O nome que essa pessoa adicionou entrara para uma lista de amigos que participarão da brincadeira, essa lista sera visivel para o usuario que administrara o sorteio
Por ultimo sera feito o sorteio do amigo secreto.
Obs: Foi implementado nesse codigo o sorteio que a mesma pessoa não podera ser sorteada novamente.
Foi utilizado nesse projeto: HTML/CSS/JAVASCRIPT.
